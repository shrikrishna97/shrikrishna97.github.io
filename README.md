## 🚀 Tech Stack

- **Languages:** HTML5, CSS3, JavaScript

---

## ✨ Features

- Dark-mode-first design with light-mode toggle (persisted via `localStorage`)
- Schema.org `Person` structured data for rich search results
- Open Graph & Twitter Card meta tags for social sharing
- Typing tagline animation & scroll-reveal cards
- Side section-indicator navigation
- Lazy-loaded images and `passive` scroll listeners for performance
- Fully responsive across mobile, tablet, and desktop
